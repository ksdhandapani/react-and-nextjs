# React and Next.js Learning Repository

Welcome to the **React and Next.js** repository! This repository contains hands-on code examples, project setups, and comprehensive documentation for learning ReactJS and Next.js.

---

## 📚 Documentation & Modules

### 1. [ReactJS Basics](./ReactJS%20Basics/ReactJS.md)
A complete, step-by-step reference guide covering core ReactJS fundamentals:
- **Introduction & Ecosystem:** Core concepts of ReactJS and combining libraries for full-stack frontend applications.
- **JSX & Babel:** Writing UI with JSX and transpiling using Babel.
- **Vite Build Tool:** Scaffolding React applications with Vite (`npm create vite@latest`).
- **Components & Styling:** Functional components, exports/imports, and modular CSS.
- **Props:** Passing data dynamically down component trees.
- **State Management (`useState`):** Managing dynamic component state and UI re-renders.
- **Context API:** Eliminating prop drilling using `createContext`, `Provider`, and `useContext`.
- **Routing (`react-router-dom`):** Configuring client-side routes with `BrowserRouter`, `Routes`, `Route`, and `Link`.
- **API Integration (`axios`):** Fetching and rendering data from external REST APIs.
